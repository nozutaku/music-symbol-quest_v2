# 音楽記号クエスト（クラス対戦版）

音符・休符・記号・用語を覚えるクイズを、クラス全員で同時に競う対戦型にしたアプリです。

## 画面

| 画面 | URL | 役割 |
| --- | --- | --- |
| 生徒用 | `index.html` | エンターコードと出席番号で参加し、出題に答える |
| 先生用 | `teacher.html` | ゲーム作成・開始・結果発表。参加者ごとの回答状況と正答率を一覧で見る |

## 遊び方

1. **先生**: `teacher.html` を開き、出題範囲を選んで「ゲームを作成する」。4桁の**エンターコード**が表示されます。
2. **生徒**: `index.html` を開き、エンターコード（4桁）と**出席番号（2桁、例: 05）**を入力して「参加する」。
3. **先生**: 参加者の出席番号が一覧に出ます。そろったら「ゲーム開始」。5秒のカウントダウンのあと、全員に同時に出題されます。
4. 全10問・**1問10秒**（全問共通）。問題と問題の間の待ち時間はなく、10秒たつと自動で次の問題になります。
5. 出題中、先生画面には参加者ごとの ○×・正答率・得点、問題ごとのクラスの正答率がリアルタイムで表示されます。
6. 全問終了後、先生が「結果発表」。上位3位を表彰し、そのあと上位10人の一覧と、生徒の画面には自分の得点・順位が表示されます。

### 得点

| 項目 | 内容 |
| --- | --- |
| 正解 | 1000点 |
| 残り時間ボーナス | 最大 +500点（回答が速いほど高い） |
| 不正解・時間切れ | 0点 |
| 同点のとき | 全問の合計回答時間が短い方が上位（未回答は10秒扱い） |

### 効果音

- 正解「ピンポーン」／不正解「ブッブー」
- シンキングタイム: 1秒ごとの時計の音（残り3秒からは高く鋭い音）、時間切れのブザー
- 開始前のカウントダウン、結果発表の太鼓・ファンファーレ

## Firebase の設定（複数の端末で対戦するために必要）

生徒の端末どうしでデータを共有するため、無料の Firebase Realtime Database を使います。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成する。
2. 「構築」→「Realtime Database」→「データベースを作成」（ロケーションは `asia-southeast1` など）。
3. 「ルール」タブに次を貼り付けて公開する（授業用の簡易設定です）。
   ```json
   {
     "rules": {
       "rooms": {
         "$code": {
           ".read": true,
           ".write": true
         }
       }
     }
   }
   ```
4. 「プロジェクトの設定」→「マイアプリ」でウェブアプリ（`</>`）を追加し、表示される `firebaseConfig` の値を
   [src/firebase-config.js](src/firebase-config.js) に貼り付ける（`databaseURL` も必須）。
5. サイトを公開（GitHub Pages など）するか、ローカルサーバーで開く。

設定しない場合は「お試しモード」で動きます。同じブラウザの別タブ同士でだけ対戦できるので、動作確認に使えます。

> **注意**: ルールは誰でも読み書きできる簡易設定です。個人情報（名前など）は扱わず、出席番号だけを使います。
> 古い部屋のデータは自動では消えません。たまに Firebase コンソールの `rooms` を削除してください。

## ローカルで動かす

```
npx http-server -p 8080 -c-1
```

`http://localhost:8080` を開きます。

## テスト

```
node --test tests/*.test.js
```

得点計算・時間割・順位づけ・回答状況の集計（`src/battle.js`）、問題の生成（`src/game.js`）、共有ストア（`src/store.js`）、効果音（`src/sound.js`）を検証します。
